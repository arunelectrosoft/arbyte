Hands-on course on the Zephyr real-time operating system, covering task scheduling, drivers, and building real-time applications on constrained embedded hardware.

## Course Outline

- Module 1: RTOS Concepts and Task Scheduling
- Module 2: Zephyr Drivers and Device Tree
- Module 3: Real-Time Application Design
- Module 4: Hands-on Board Bring-up Project

## Classroom Training Hours
**32 hours** of instructor-led classroom training, combined with supervised hands-on lab work.
