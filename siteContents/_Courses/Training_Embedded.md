Learn to design and develop embedded systems through hands-on work with microcontrollers, Linux, connectivity, secure boot, firmware-over-the-air updates, and real-world engineering practices.

## Course Outline

- Module 1: Microcontrollers and Peripherals
- Module 2: Embedded Linux Fundamentals
- Module 3: Connectivity and Communication Protocols
- Module 4: Secure Boot and FOTA Updates
- Module 5: Real-World Capstone Project

## Classroom Training Hours
**48 hours** of instructor-led classroom training, combined with supervised hands-on lab work.
