Automotive-focused course covering AUTOSAR fundamentals, ECU software development, functional safety, and security practices for vehicle software systems.

## Course Outline

- Module 1: AUTOSAR Fundamentals
- Module 2: ECU Software Development
- Module 3: Functional Safety (ISO 26262)
- Module 4: Automotive Security and Integration Project

## Classroom Training Hours
**40 hours** of instructor-led classroom training, combined with supervised hands-on lab work.
