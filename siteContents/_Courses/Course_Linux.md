Practical Linux course covering the kernel, device drivers, build systems (Yocto/Buildroot), and system administration skills needed for embedded Linux platforms.

## Course Outline

- Module 1: Linux Kernel and Boot Process
- Module 2: Device Driver Development
- Module 3: Embedded Build Systems (Yocto/Buildroot)
- Module 4: System Administration and Scripting Project

## Classroom Training Hours
**36 hours** of instructor-led classroom training, combined with supervised hands-on lab work.
